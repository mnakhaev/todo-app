# Ozon: анализ отзывов — расширение для Chrome

Открываете карточку товара на Ozon → нажимаете кнопку **«★ Анализ отзывов»** в правом нижнем углу →
расширение скачивает **все** отзывы о товаре, проверяет каждый на признаки накрутки и показывает:

* **вердикт** — риск накрутки по шкале 0–100 («естественно» / «есть признаки» / «высокий риск»);
* **долю вероятно фейковых и сомнительных отзывов**;
* **рейтинг с фейками и без них** — насколько накрутка завышает оценку;
* распределение оценок с разбивкой на настоящие/сомнительные/фейковые;
* долю отзывов с подтверждённой покупкой и с фото;
* признаки накрутки по товару в целом (всплески 5★ в один день, «без покупки» выше «с покупкой», поляризация оценок, «разгон» карточки…);
* график отзывов по месяцам с долей фейков;
* **плюсы и минусы** — частые темы только из настоящих отзывов;
* список подозрительных отзывов с причинами (одинаковые тексты сгруппированы).

Результат кешируется для товара — при повторном открытии панель покажет его сразу (кнопка «обновить» пересчитает).
Кнопка «Скачать отзывы (JSON)» сохраняет файл, совместимый с Python-скриптом
`../ozon-review-analyzer` (`python ozon_reviews.py --from-json файл.json --llm`).

## Установка (1 минута)

1. Скачайте папку `ozon-review-extension` (клонируйте репозиторий или скачайте ZIP ветки и распакуйте).
2. Откройте в Chrome адрес `chrome://extensions`.
3. Включите **«Режим разработчика»** (переключатель справа вверху).
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку `ozon-review-extension`
   (ту, где лежит `manifest.json`).
5. Откройте любой товар на ozon.ru (если вкладка уже была открыта — обновите её, F5).

Работает также в Яндекс Браузере, Edge и других браузерах на Chromium.

## Как определяются фейковые отзывы

Каждый отзыв проверяется набором признаков. Итог считается как `score = 1 − Π(1 − вес)`:
один слабый признак не делает отзыв фейком, несколько — делают.
`score ≥ 50%` — «вероятно фейк», `30–50%` — «сомнительный».

| Признак | Вес |
|---|---|
| Почти дословно совпадает с другим отзывом | 0.45 |
| У автора несколько отзывов на этот товар | 0.30 |
| Нет отметки о покупке | 0.25 |
| 5★ и очень короткий текст (< 8 слов), без фото | 0.25 |
| Шаблонные рекламные фразы («всем рекомендую», «качество на высоте»…) | 0.20 |
| Опубликован во всплеске 5★ за один день | 0.20 |
| Отзыв за вознаграждение (баллы/кешбэк) | 0.20 |
| Оценка противоречит тексту | 0.20 |
| Только похвала, минусов «нет», без деталей | 0.15 |
| Избыток «!!!», капса, эмодзи | 0.10 |
| Автор скрыт | 0.05 |

**Вердикт** (0–100) складывается из доли фейков (основной вклад), доли сомнительных и признаков
на уровне товара. Для товаров с < 15 отзывами оценка смягчается — данных мало.

Это вероятностная оценка, а не доказательство — у каждого подозрительного отзыва видны причины.

## Как это работает технически

* Контент-скрипт работает только на `ozon.ru`. Кнопка появляется только на страницах `/product/…`
  (Ozon — SPA, переходы между товарами отслеживаются).
* Отзывы берутся из внутреннего API витрины `/api/entrypoint-api.bff/page/json/v2?url=/product/…/reviews/?page=N`
  прямо из вкладки — с вашими куками, поэтому антибот Ozon не мешает. Между страницами пауза 0.6 с.
* Расширение ничего не отправляет на сторонние серверы. Разрешения: `storage` (кеш результатов) и `activeTab` (попап).
* Интерфейс — в Shadow DOM; тексты отзывов экранируются.

Парсер (`src/fetcher.js`) не привязан к конкретному виджету Ozon: он ищет в ответе объекты с полями
`score/rating` + `comment/positive/negative` + `uuid/id`, поэтому обычно переживает изменения вёрстки.
Если отзывы всё же перестанут находиться — откройте DevTools → Network, найдите запрос
`entrypoint-api.bff/page/json/v2?url=…reviews…` и сохраните его ответ: по нему парсер легко поправить.

## Разработка

```bash
node --test tests/*.test.js   # тесты анализатора и парсера
```

Файлы: `manifest.json`, `src/analyzer.js` (эвристики), `src/fetcher.js` (сбор отзывов),
`src/content.js` + `src/panel.css` (панель), `popup.html/js` (попап по клику на иконку).
