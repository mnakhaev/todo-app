# Ozon Review Analyzer

Скрипт принимает ссылку на товар Ozon, собирает все отзывы и выдаёт отчёт:

* **долю вероятно фейковых отзывов** (+ «сомнительных») и причины для каждого;
* **рейтинг с фейками и без них** — насколько накрутка завышает оценку;
* **плюсы и минусы товара** — частотные темы из настоящих отзывов с примерами;
* опционально — **углублённый анализ через Claude** (`--llm`): смысловая проверка фейков, сгруппированные плюсы/минусы и итог для покупателя.

## Установка

```bash
cd ozon-review-analyzer
pip install -r requirements.txt
python -m playwright install chromium
```

## Запуск

```bash
python ozon_reviews.py "https://www.ozon.ru/product/nazvanie-tovara-123456789/" \
    --save reviews.json --report report.md --csv reviews.csv
```

Откроется окно Chromium. У Ozon жёсткая антибот-защита: если появится проверка
«Вы не робот», пройдите её в этом окне — скрипт дождётся. Cookies сохраняются в
`~/.ozon-review-analyzer/browser-profile`, поэтому при следующих запусках проверки обычно нет.

Повторный анализ уже скачанных отзывов (без обращения к Ozon):

```bash
python ozon_reviews.py --from-json reviews.json
python ozon_reviews.py --from-json reviews.json --llm        # + анализ через Claude
```

Для `--llm` нужен ключ `ANTHROPIC_API_KEY`. По умолчанию модель `claude-opus-5`
(`--llm-model`), в модель уходит до 800 отзывов (`--llm-max-reviews`; все подозрительные — в приоритете).

| Флаг | Назначение |
|---|---|
| `--save FILE` | сохранить сырые отзывы в JSON |
| `--report FILE` | отчёт в Markdown |
| `--csv FILE` | все отзывы с оценкой подозрительности (открывается в Excel) |
| `--json-out FILE` | полный результат анализа в JSON |
| `--max-pages N` | ограничить число страниц отзывов |
| `--headless` | без окна браузера (Ozon блокирует чаще) |
| `--debug-dir DIR` | сохранять сырые ответы Ozon — если парсер перестал находить отзывы |

## Как определяются фейковые отзывы

Каждый отзыв проверяется набором признаков, у каждого — вес. Итог считается как
`score = 1 − Π(1 − вес)`: один слабый признак не делает отзыв фейком, несколько — делают.
`score ≥ 0.5` — «вероятно фейк», `0.3–0.5` — «сомнительный».

| Признак | Вес | Логика |
|---|---|---|
| Дубликат | 0.45 | текст почти дословно совпадает с другим отзывом (Jaccard по 3-словным шинглам ≥ 0.6) |
| Один автор — несколько отзывов | 0.30 | на один и тот же товар |
| Без подтверждённой покупки | 0.25 | нет отметки Ozon «товар куплен» |
| Короткий 5★ | 0.25 | < 8 слов, без фото, без конкретики |
| Шаблонные фразы | 0.20 | «всем рекомендую», «качество на высоте», «продавцу спасибо»… составляют бо́льшую часть текста |
| Всплеск | 0.20 | 5★ опубликован в день аномально большого числа 5★ (медиана + 5·MAD) |
| За вознаграждение | 0.20 | упоминание баллов/кешбэка за отзыв |
| Оценка ≠ текст | 0.20 | 5★ с негативным текстом или 1–2★ с восторженным |
| Минусов «нет» + превосходные степени | 0.15 | без цифр и деталей |
| Эмоциональность | 0.10 | много «!!!», капса, эмодзи |
| Скрытый автор | 0.05 | очень слабый признак, лишь добавка к остальным |

Дополнительно по товару в целом: неестественное распределение оценок (почти нет 2–4★ или
поляризация 5★/1★), разница рейтинга с/без подозрительных отзывов, отзывы без покупки
заметно выше отзывов с покупкой, ранние отзывы заметно лучше поздних («разгон» карточки),
отзывы собраны с разных вариантов товара.

Это вероятностная оценка, а не доказательство — в отчёте и CSV для каждого отзыва видны причины.

## Плюсы и минусы

Берутся только отзывы, не помеченные как фейк. Источники плюсов — поле «Достоинства» и
комментарии к 4–5★; минусов — поле «Недостатки» и комментарии к 1–2★ (3★ раскладываются по
тональности). Тексты режутся на фразы, по словам и парам слов считается, в скольких отзывах
тема встречается; похожие темы схлопываются. Для более «человеческой» группировки используйте `--llm`.

## Ограничения

* Ozon не даёт официального API отзывов, скрипт использует внутренний API витрины
  (`/api/entrypoint-api.bff/page/json/v2`). Если Ozon поменяет формат — запустите с
  `--debug-dir debug` и посмотрите сырые ответы; парсер ищет отзывы по полям
  `score/rating` + `comment/positive/negative` + `uuid/id`, поэтому устойчив к перестановкам виджетов.
* Соблюдайте правила Ozon: не уменьшайте `--delay` и не запускайте массово.
